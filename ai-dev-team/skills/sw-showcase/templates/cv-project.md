# Template：CV Selected Projects 段落（英文）

> 跟用戶 CV「// SELECTED PROJECTS」格式。只輸出 markdown 俾用戶自行 paste（R7）。

## 格式

```markdown
## **<App Name> — <5–8 word tagline>**        <YYYY> to <Present | YYYY>

**Personal Product (Solo Architect & Developer)**

 – <一句：係乜、為邊個、解決咩問題；built end-to-end through the ai-dev-team system>

  - <Bullet 1：架構 / 核心技術決定 + 技術棧>
  - <Bullet 2：最有技術含量嘅 feature，量化（例如 480 questions、14-day probe window）>
  - <Bullet 3：工程紀律 + 數字（tests、PRs、versions、active days、Claude sessions）>
  - <Bullet 4（可選）：用戶 / 產品成果（真實用量數據先寫）>
```

## 規則

- 3–4 個 bullet，每個以強動詞開頭（Architected / Built / Engineered / Shipped / Established）
- 每個 bullet 最少一個具體數字或技術名詞
- 角色寫法同 CV 其他 project 一致：`Personal Product (Solo Architect & Developer)`
- R6 app：唔放 link；描述用 "personal-use" 字眼，唔好暗示商業發佈
- 輸出下面加一句 note：建議插入位置（按年份排序）
