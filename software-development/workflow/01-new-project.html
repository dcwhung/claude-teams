新項目開發流程

從用戶需求到生產部署的完整流程

總覽 新項目流程 功能開發 TDD Bug 修復 緊急修復 接手舊項目 Review → 部署

新項目端對端流程

新項目從用戶提出需求開始，經過規劃（Spec + Plan）→ 逐功能 TDD 開發 → QA 測試 → DevOps 部署，每個 session 結束執行 /session-log。
