快速參考

# 啟動方式
/start ai-dev-team ← 載入團隊，詢問今次目標
/start ai-dev-team --task=fix --ticket=CUI-0001 ← 指定修復任務
/start ai-dev-team --task=postmortem ← EM 主導根源分析

# 開發循環
/spec → /plan → /feature → /review → /test → /deploy

# 評分門檻
≥ 90 分 → 可以 merge（/feature, /fix, /refactor）
≥ 75 分 → Hotfix 緊急情況最低門檻
任何 🔴 Critical → 無論總分，一律不合格

# 每個 session 結束
/session-log ← 全體執行，記錄 session
